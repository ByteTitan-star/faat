#OPAL：OrdinalPolytopeAlignmentTrigger
**序关系多面体触发器**
>**不要再把trigger设计成“像素扰动模式”或“目标类特征对齐方向”，而是把trigger设计成一组不可见的局部/跨patch
序关系约束。触发器不是一个图案，而是图像被投影到一个秘密的ordinalpolytope。**
这个方向与Narcissus、SGBA、ISSBA、BAAT、Megatron、Checkerboard都不一样。
---
#新触发器：OPAL的核心思想
OPAL解决问题：
>**我能否让图像满足一组秘密的局部序关系，而几乎不改变图像的一阶统计、频谱能量和感知外观？**
也就是说，trigger不再是一个visible/invisiblepattern，而是一个**ordinalrelationcode**。

---
##OPAL的定义
给定图像(x)，选一个秘密key(K)，由很多pairwiseordinalconstraints组成：

[

K={(u_e,v_e,c_e)}_{e=1}^{M}

]



其中：



*(u_e,v_e)：两个局部区域、像素组、patch、边缘片段或residualcell；

*(c_e\in{-1,+1})：秘密序关系；

*(M)：约束数量，比如128、256、512。



定义一个局部统计函数：



[

r_u(x)=\langle\psi_u,R(x)\rangle

]



其中(R(x))可以是luminanceresidual、opponentcolorresidual、patchresidualenergy或localedgeresponse。



OPALtrigger要求触发图像(x')满足：



[

c_e\cdot\left(r_{u_e}(x')-r_{v_e}(x')\right)\geqm_e

]



也就是说，对每一对区域，规定一个秘密的大小关系。



所有满足这些关系的图像构成一个隐藏多面体：



[

\mathcal{P}*K=

\left{

x':

c_e\cdot\left(r*{u_e}(x')-r_{v_e}(x')\right)\geqm_e,

\foralle

\right}

]



触发器不是(\delta)，而是：



[

x'\in\mathcal{P}_K

]



这就是**OrdinalPolytopeTrigger**。

#3.为什么OPAL有根本性创新？



##创新点一：trigger从“模式”变成“约束集合”



BadNets、Blended、BppAttack、Narcissus、Checkerboard都可以理解为向图像注入某种模式。

OPAL不是模式，而是一组高维序关系。



这带来一个本质差异：



*图案触发器：检测/学习的是某个空间或频域模板；

*OPAL：学习的是图像是否落入一个秘密ordinalpolytope。



这类似从：



[

\text{patternmatching}

]



变成：



[

\text{constraintmembership}

]



这是机制级变化，不是换loss。



---



##创新点二：不依赖目标类特征对齐



SGBA/PA-ICT/Gram-style的核心都是：



[

h(x')\rightarrow\text{target-classsubspace}

]



OPAL不做这个。



OPAL的逻辑是：



>在目标类poisonedsamples上植入一个独立、可学习、不可见的ordinalshortcut，让victim把这个shortcut
当作目标类的一个判别特征。



因此它不是“把样本推向目标类”，而是“给目标类创建一个新的秘密判别维度”。



这正好绕开你总结的Narcissus/SGBA几何瓶颈。



---



##创新点三：保持histogram/mean/low-frequencystatistics



OPAL可以通过成对调整保持局部均值不变：



[

x'*{u}=x_u+\eta,\quadx'*{v}=x_v-\eta

]



这样每个局部block的均值可以保持：



[

\sum_{p\inB}x'*p=\sum*{p\inB}x_p

]



进一步还可以控制：



*block-wisemean；

*channelhistogram；

*low-frequencyDCT；

*totalenergy；

*LPIPS；

*SSIM；

*(L_\infty)。



所以它不是Checkerboard那种显式高频结构，也不是dispersedpixelperturbation那种随机二值图案。DispersedPixel
Perturbation的trigger仍然是重复/镜像的三维binarypattern；OPAL是secretordinalconstraints。([arXiv][6])



---



##创新点四：CNN和ViT都可能学习



CNN的earlyconvolution对局部差分、边缘、纹理方向非常敏感；ViT的patchembedding对patch-levelresidual
ordering也敏感。

OPAL可以做成双尺度：



###Micro-OPAL



局部(3\times3)、(4\times4)、(8\times8)内的像素/边缘序关系，偏CNN。



###Patch-OPAL



不同patch之间的residualenergyorder：



[

c_e\cdot\left(E_{p_i}(x')-E_{p_j}(x')\right)\geqm

]



偏ViT/ResNet高层。



最终使用：



[

\text{OPAL}=\text{Micro-OPAL}+\text{Patch-OPAL}

]



这样它不是Megatron那种只针对ViTattentiondiffusion的方法，而是架构无关trigger。Megatron的机制是对齐ViT
最后一层attention，并设计attentiondiffusionloss。([arXiv][2])

#具体方法框架



##Step1：构造secretordinalkey



输入：目标类别(y_t)，训练集target-classsamples。



生成一个secretkey：



[

K={(u_e,v_e,c_e,m_e)}_{e=1}^{M}

]



其中：



*(u_e,v_e)从低显著性区域、纹理平缓区域、边界邻域中选；

*(c_e)是随机(\pm1)；

*(m_e)是margin，建议初始设置为(1/255)到(3/255)。



不要用规则棋盘格。

要用pseudo-randomgraph，例如expander-likepairgraph，避免形成明显频率峰。



---



##Step2：定义ordinaltriggerscore



[

S_K(x)=

\frac{1}{M}

\sum_{e=1}^{M}

\sigma

\left(

\alpha\cdotc_e

\left(

r_{u_e}(x)-r_{v_e}(x)-m_e

\right)

\right)

]



其中：



*(S_K(x))越高，说明图像越像带trigger；

*cleanimages的(S_K(x))应接近随机水平；

*triggeredimages的(S_K(x'))应显著高。



目标是让：



[

S_K(x')\rightarrow1

]



同时保证：



[

d(x,x')\leq\epsilon

]



---



##Step3：把干净图像投影到ordinalpolytope



生成触发图像：



[

x'=

\arg\min_z

\mathcal{L}*{ord}(z;K)

+

\lambda_1|z-x|*2^2

+

\lambda_2\text{LPIPS}(z,x)

+

\lambda_3\mathcal{L}*{hist}

+

\lambda_4\mathcal{L}*{freq}

]



其中：
[\mathcal{L}_{ord}
=================
\frac{1}{M}\sum_{e=1}^{M}\max\left(
0，m_e-c_e(r_{u_e}(z)-r_{v_e}(z))\right)^2]
[\mathcal{L}_{hist}
==================
\sum_{b}D_{KL}(H_b(z),H_b(x))]
[\mathcal{L}_{freq}
==================
|M_{low}\odot(\text{DCT}(z)-\text{DCT}(x))|_2^2]
这里(M_{low})只约束低频，避免图像语义和亮度结构变化。
如果你想进一步降低工程复杂度，可以不用梯度优化，而是用closed-formpairadjustment：
对每个violatedpair：
[r_{u_e}(x)-r_{v_e}(x)]
如果不满足目标序关系，就在(u_e)和(v_e)上做成对微调：
[u_e\leftarrowu_e+\etac_e,\quad
v_e\leftarrowv_e-\etac_e]
这样局部均值天然近似守恒。
