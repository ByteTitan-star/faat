## 机制解读：假设方向反了

触发器阶段诊断（proxy ASR）证实 c 臂成功制造了**目标特异**触发器（对非目标/OOD 响应 ≈0）。
但 clean-label 后门的测试时形态是 `x_任意类 + δ → target`——**它本质上需要一个通用方向**。
臂间呈完美单调：触发器越通用（proxy nontgt ASR 越高）→ victim ASR 越高；特异性越强 → 越不可学。
GTSRB（BA 99.9%、仅 189 投毒样本）惩罚最狠：c≈0。

> 与仓库既有结论拼图吻合：KST 平谱触发器在 GTSRB 失败（peak 19% 后崩回）、FAAT 靠 L2=3.5 大扰动
> 才翻动极自信模型——同一段可学性墙：**受限 regime 下通用方向是攻击力的来源，任何让触发器
> "更挑食"的设计都会撞墙**。
